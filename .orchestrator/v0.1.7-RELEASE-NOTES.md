## New Features

### Multi-Architecture Build Support
**Commits**: `e619a05`, `b910597`

Added comprehensive support for building on both ARM64 and x86_64 architectures:

- **Automatic Architecture Detection**: Build system now auto-detects target architecture and selects appropriate native binaries
- **Native Binary Support**: Properly handles platform-specific binaries for `sharp` and `better-sqlite3` packages
- **Architecture Verification**: Binary validation with `file` command ensures correct architecture after download
- **Build-Time Checks**: Fail-fast on unsupported platforms with clear error messages
- **Comprehensive Documentation**: 309 lines of multi-architecture build documentation added to `DEPLOY-v0.1.7.md`

**Impact**: The system can now be built and deployed on x86_64 development machines in addition to ARM64 Raspberry Pi devices, improving development workflow and testing capabilities.

### Deployment Validation & Error Handling
**Commits**: `104da95`, `34cd4b4`

Significantly enhanced deployment reliability with comprehensive validation:

- **NetworkManager Validation**: Validates WiFi Access Point activation and active state with 2-second stabilization delay
- **Database Schema Validation**: Verifies ≥30 tables exist before marking database as initialized
- **Pipeline Error Detection**: Changed from `set -e` to `set -euo pipefail` to catch pipeline failures
- **Error Traps with Rollback**: Automatic cleanup on failure with rollback logic for NetworkManager and database operations
- **Improved Error Messages**: Enhanced 43 error messages with context, causes, impact statements, and actionable remediation commands

**Impact**: Deployments now validate critical components and provide actionable diagnostics when failures occur, preventing silent failures that previously required manual investigation.

## Bug Fixes

### Critical: Nginx API Routing Fixed
**Commit**: `21c0599`

**Issue**: Nginx reverse proxy configuration had a trailing slash in `proxy_pass` directive, causing it to strip the `/api` prefix from all API requests, resulting in 404 errors for all API endpoints.

**Fix**: Removed trailing slash from `proxy_pass http://localhost:4000/` → `proxy_pass http://localhost:4000`

**Impact**: All API endpoints now route correctly without 404 errors.

### Critical: systemd Service Files Missing from Package
**Commit**: `e619a05`

**Issue**: The `.deb` package build script was not copying systemd service unit files, preventing services from starting after installation.

**Fix**:
- Added systemd directory copy operations to `build-deb.sh` (lines 386-401)
- Added validation checks to ensure files are present before packaging (lines 713-727)

**Impact**: Services (`escapeplan-api.service`, `escapeplan-web.service`) now start successfully after installation.

### Critical: TypeScript Compilation Errors (360 errors)
**Commit**: `1b2be4c` (security fixes also regenerated lockfile)

**Issue**: Version conflict between two installations of `better-sqlite3` (9.6.0 vs 12.4.1) causing 360 TypeScript compilation errors.

**Fix**:
- Removed `pnpm-lock.yaml` and cleaned `node_modules`
- Reinstalled dependencies with single version (12.4.1)
- Verified with full test suite (154/154 tests passing)

**Impact**: Zero TypeScript compilation errors, builds succeed, all tests passing.

### Shellcheck Linting Errors
**Commit**: `34cd4b4`

**Issue**: 37 shellcheck errors/warnings across deployment scripts, including 11 critical errors:
- SC2086: Unquoted variables causing globbing/word splitting (7 instances)
- SC2010: Using `ls | grep` instead of `find` (1 instance)
- SC2188: Empty redirect (1 instance)
- SC2168: Local variables outside functions (2 instances)

**Fix**: Resolved all 11 critical errors with proper quoting, command substitution, and function scope.

**Impact**: Deployment scripts now pass shellcheck critical validation, reducing risk of runtime failures from variable expansion issues.

### Security Vulnerabilities
**Commit**: `1b2be4c`

**Issue**: 3 security vulnerabilities detected:
- esbuild ≤0.24.2 (CORS vulnerability) - MODERATE severity
- cookie <0.7.0 (out of bounds characters) - LOW severity

**Fix**: Added pnpm overrides to force vulnerable packages to secure versions:
- `esbuild@<=0.24.2` → `>=0.25.0`
- `cookie@<0.7.0` → `>=0.7.0`

**Impact**: Zero known security vulnerabilities in production dependencies.

## Upgrade Instructions

### From v0.1.0 to v0.1.7

1. **Pull Latest Code**
   ```bash
   git fetch origin
   git checkout v0.1.7
   ```

2. **Install Dependencies**
   ```bash
   pnpm install
   ```

3. **Rebuild All Packages**
   ```bash
   pnpm build
   ```

4. **Run Tests** (verify everything works)
   ```bash
   pnpm test
   pnpm lint
   ```

5. **Build .deb Package**
   ```bash
   pnpm run build:deb
   ```

6. **Install on Raspberry Pi**
   ```bash
   # Copy to Pi
   scp dist/escapeplan_0.1.7_arm64.deb pi@escapeplan.local:

   # Install
   ssh pi@escapeplan.local
   sudo dpkg -i escapeplan_0.1.7_arm64.deb

   # Verify services started
   sudo systemctl status escapeplan-api escapeplan-web

   # Run health check
   sudo bash /opt/escapeplan/scripts/health-check.sh
   ```
