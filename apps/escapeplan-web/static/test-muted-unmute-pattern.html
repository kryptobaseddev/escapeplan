MUTED→UNMUTED AUTOPLAY PATTERN TEST

TEST OBJECTIVE

Determine if the muted→unmuted pattern can bypass browser autoplay restrictions:

  • Start media with muted attribute (should autoplay)
  • Programmatically set .muted = false after playback starts
  • Verify if unmuting works WITHOUT additional user interaction

PATTERN 1: HTML muted attribute + unmute on canplay

Video has muted attribute in HTML, then unmuted via JS when canplay fires

PATTERN 2: JS muted=true + unmute after play() promise

Video muted via JS, play() called, then unmuted in .then()

PATTERN 3: Audio element - muted + unmute

Audio element with muted attribute, unmuted on canplay

PATTERN 4: User gesture + delayed unmute

User clicks to start, then video unmutes after 2 seconds
